# Serene Space Design

Crie um site profissional, moderno, elegante e de alto padrão para uma psicóloga, com aparência de um projeto desenvolvido por uma agência profissional especializada em sites para profissionais da saúde.

OBJETIVO PRINCIPAL:
Criar uma experiência visual sofisticada que transmita confiança, acolhimento, profissionalismo, credibilidade e autoridade, incentivando o visitante a conhecer o trabalho da psicóloga e entrar em contato para agendar uma consulta.

IMPORTANTE — ECONOMIA DE CRÉDITOS:

* Execute o projeto completo de uma única vez.
* Antes de implementar, estruture mentalmente todo o site e suas páginas.
* Evite alterações desnecessárias, refatorações repetitivas ou mudanças cosméticas que não agreguem valor.
* Não fique perguntando detalhes que possam ser resolvidos com escolhas profissionais.
* Utilize componentes reutilizáveis.
* Não recrie componentes já existentes.
* Priorize código limpo, organizado, responsivo e eficiente.
* Faça todas as funcionalidades principais nesta primeira implementação.
* Não adicione funcionalidades fictícias que não possam funcionar.
* Se alguma informação da profissional estiver faltando, utilize textos claramente identificados como PLACEHOLDER para posterior substituição.

DIREÇÃO VISUAL:
Criar uma estética premium, minimalista e sofisticada.

Paleta sugerida:

* Branco/off-white como base.
* Bege ou nude muito suave.
* Verde sálvia ou azul petróleo como cor de destaque.
* Tons escuros para textos.
* Pequenos detalhes dourados discretos para transmitir sofisticação.

Evitar:

* Visual genérico de template.
* Excesso de cores.
* Excesso de animações.
* Design infantil.
* Elementos exagerados.
* Aparência de site automático de IA.

IMAGENS:
Utilize imagens profissionais, realistas e de alta qualidade, com aparência fotográfica premium e resolução adequada para telas grandes/retina.

As imagens devem transmitir:

* acolhimento;
* tranquilidade;
* confiança;
* profissionalismo;
* ambiente terapêutico;
* bem-estar.

Não utilize imagens pixeladas, genéricas ou de baixa qualidade.

Se não houver imagens fornecidas, utilize placeholders de alta qualidade facilmente substituíveis posteriormente.

ESTRUTURA DO SITE:

1. HEADER
   Criar um cabeçalho elegante e fixo.

Itens:

* Logo/nome da psicóloga.
* Início.
* Sobre.
* Atendimento.
* Especialidades.
* Como funciona.
* Depoimentos.
* FAQ.
* Contato.

Adicionar botão de destaque:
"Agendar atendimento"

No celular, utilizar menu hamburger.

2. HERO / PRIMEIRA DOBRA

Criar uma primeira seção extremamente profissional e chamativa.

Título principal:
"Cuide da sua saúde emocional com acolhimento, segurança e acompanhamento profissional."

Subtítulo:
"Um espaço de escuta, acolhimento e desenvolvimento emocional, pensado para você."

Adicionar dois botões:
"Agendar atendimento"
"Conhecer meu trabalho"

Ao lado, apresentar uma fotografia profissional da psicóloga ou placeholder premium para foto profissional.

Adicionar pequenos elementos visuais de confiança abaixo do CTA, sem inventar certificações ou números.

3. SEÇÃO SOBRE A PSICÓLOGA

Criar uma seção contando a trajetória profissional.

Estrutura:

* Foto profissional.
* Nome da psicóloga.
* CRP:Aleatorio
* Cidade/região:Adamantima-Sp
* Texto sobre formação, experiência, abordagem e propósito.

Não inventar formação, especializações, certificados ou experiência.

Usar placeholders quando as informações não forem fornecidas.

4. ESPECIALIDADES

Criar cards modernos para as áreas de atendimento.

Exemplos de placeholders:

* Ansiedade
* Autoconhecimento
* Estresse
* Relacionamentos
* Desenvolvimento emocional
* Autoestima
* Orientação psicológica
* Outras demandas

Importante: deixar as áreas facilmente editáveis.

5. COMO FUNCIONA

Criar uma seção explicando o processo em 3 ou 4 etapas:

01 — Primeiro contato
02 — Conversa inicial
03 — Definição do acompanhamento
04 — Acompanhamento psicológico

Usar ícones minimalistas e microanimações discretas.

6. DIFERENCIAIS

Criar uma seção visual destacando os diferenciais reais do atendimento, sem inventar informações.

Exemplos:

* Atendimento humanizado.
* Ambiente acolhedor.
* Escuta individualizada.
* Atendimento personalizado.
* Privacidade e respeito.
* Acompanhamento profissional.

7. DEPOIMENTOS

Criar uma seção elegante para depoimentos.

IMPORTANTE:
Não inventar depoimentos reais.

Utilizar placeholders como:
"[Depoimento de paciente — substituir pelo depoimento autorizado]"

Criar cards com aparência premium e opção de adicionar novos depoimentos futuramente.

8. SEÇÃO DE CONFIANÇA

Criar uma seção visual com informações profissionais.

Campos editáveis:

* CRP
* Formação
* Especializações
* Modalidade de atendimento
* Localização
* Atendimento online/presencial

Não criar informações falsas.

9. FAQ

Criar perguntas frequentes:

* Como funciona a primeira sessão?
* Quanto tempo dura uma sessão?
* O atendimento pode ser online?
* Como faço para agendar?
* Qual é a frequência das sessões?
* O atendimento é confidencial?
* Como saber se a psicoterapia é indicada para mim?

Criar respostas profissionais, acolhedoras e informativas, sem prometer resultados.

10. CTA FINAL

Criar uma seção forte e elegante:

"Dar o primeiro passo também é uma forma de cuidar de você."

Texto:
"Se você sente que está na hora de olhar com mais atenção para sua saúde emocional, entre em contato para saber mais sobre o atendimento."

Botão:
"Agendar atendimento"

11. CONTATO

Criar área de contato profissional.

Campos:

* Nome
* E-mail
* Telefone
* Mensagem

Adicionar botão:
"Enviar mensagem"

Adicionar também botão de WhatsApp.

O WhatsApp deve utilizar:
+55 18 99618-6802

Criar mensagem automática:
"Olá! Gostaria de saber mais sobre o atendimento psicológico."

12. RODAPÉ

Adicionar:

* Nome da psicóloga.
* CRP.
* Cidade.
* Links de navegação.
* WhatsApp.
* Instagram: https://www.instagram.com/angelatesta.eusoupsico/
* Aviso de privacidade.
* Copyright.

RESPONSIVIDADE:
O site deve funcionar perfeitamente em:

* Desktop.
* Notebook.
* Tablet.
* Smartphone.

Criar layout mobile específico quando necessário, não apenas diminuir o desktop.

PERFORMANCE:

* Otimizar imagens.
* Lazy loading onde apropriado.
* Evitar bibliotecas desnecessárias.
* Evitar animações pesadas.
* Garantir carregamento rápido.
* Código organizado e eficiente.

ANIMAÇÕES:
Usar apenas microinterações premium:

* Fade-in suave.
* Hover elegante.
* Transições rápidas.
* Pequenas animações ao entrar na viewport.

Não exagerar nas animações.

SEO:
Configurar:

* Title profissional.
* Meta description.
* Open Graph.
* Estrutura semântica HTML.
* Headings organizados.
* Alt text nas imagens.
* URLs amigáveis.

ACESSIBILIDADE:

* Contraste adequado.
* Navegação por teclado.
* Labels nos formulários.
* Alt text.
* Botões claramente identificados.

PRIVACIDADE:
Como o site é de uma profissional da saúde, não coletar informações sensíveis desnecessárias.
Adicionar aviso de privacidade e utilizar os dados dos formulários apenas para contato/agendamento.

RESULTADO ESPERADO:
O resultado final deve parecer um site premium desenvolvido por uma agência especializada, e não um template genérico.

Priorize:

1. Credibilidade.
2. Elegância.
3. Clareza.
4. Conversão para contato/agendamento.
5. Experiência do usuário.
6. Responsividade.
7. Performance.
8. Facilidade de edição.

IMPORTANTE:
Não invente dados pessoais, CRP, certificados, formação, endereço, depoimentos ou resultados clínicos.

Deixe todos os dados específicos facilmente substituíveis.

Antes de finalizar, faça uma revisão completa visual e funcional do projeto e corrija problemas de responsividade, espaçamento, botões, navegação, formulários e links.
